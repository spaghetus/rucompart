# Rucompart

[Demo](https://u.wolo.dev/~willow/rucompart-demo.mp4?k=Oj_Y7EeT)

## Usage

1. Follow the `tarpc` docs to create a service: <https://docs.rs/tarpc>
2. Invoke `rucompart::compartmentalize!`, passing the name of the compartment, the `ServeFoo` type generated by `tarpc`, your service implementation, the `FooClient` stub generated by `tarpc`, and a `setup` function that should run when starting the compartment.
3. In `main`, either start as a standalone compartment or connect to a compartment using a socket or a fork.
   1. I'd like to automate this, but it'll require some more macro chicanery.
4. Start the `tokio` runtime (strictly *after* starting any fork-compartments) and consume the compartment's API as desired.
